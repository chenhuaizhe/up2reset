怎么用

你不用管理一个窗口。计时器待在菜单栏里，直到所有屏幕变暗。那就是它该做的事。

做完这三步就算会用：在菜单栏找到它、打开开机自启、第一次遮罩出现时站起来点「已走动」。其余都是可选。

1. 装完以后

打开 Up2Reset。Dock 里没有窗口。这不是故障。

  1. 看屏幕右上角菜单栏，找那个小计时器，不要在 Dock 里找。
  2. 如果只看到折叠箭头 »（隐藏的菜单栏项目），把计时器拖出来，免得下次找不到。
  3. 点计时器。会弹出面板：已工作时间、下次休息、暂停、设置。

现在 App Store 现网仍叫 Up2Stretch（1.2.1），和 Up2Reset 是同一个 App。1.3.0 已提交审核，过审后商店显示名改成 Up2Reset。

2. 第一个小时

  1. 第一次启动会问要不要开机自启。每天用就开。一个要你记得打开的久坐提醒，等于没有提醒。之后也能改：面板 → 设置 → 开机自启。
  2. 系统问通知时允许。那是休息前大约两分钟的横幅，之后可以关掉。
  3. 不要开辅助功能。Pro 闲置检测读的是系统闲置时长，不是全局键盘监听。
  4. 让它挂着，回去干活。免费档间隔是 30 / 45 / 60 分钟，默认大约 60 分钟。

3. 所有屏幕变暗时

这就是休息。站起来，动一动。不要把它当通知划掉。

  1. 主按钮：已走动（英文界面是 I moved）。确认这次休息，开始下一段工作。
  2. 开会走不开：点跳过。默认 10 分钟后再来。跳过不是把今天剩下的提醒都取消。
  3. 如果开了工作日志，可以写一句刚才在做什么。下一轮坐下时至少还记得做到哪。
  4. 想现在就休息：面板 → 开始休息。

1.3.0（审核中，商店里还没有）可以把跳过 / 已走动改成按住 3 秒，避免误触关掉。

4. 开会、吃饭、离开座位

  1. 开会或看电影前，在面板点暂停。坐下后再点继续。一直暂停，就不会再提醒。
  2. 合盖或锁屏：工作计时会停。人不在座位上，不该把这段算成工作。
  3. 一回来遮罩就弹：硬计时器在你坐着但不打字时也在走（阅读、看视频也算坐着）。走前先暂停，或打开 Pro 闲置检测。
  4. 重新计时会从零开始这一段。现网 1.2.1 按钮仍可能显示「重置」。

5. 值得改的设置

面板 → 设置。四个 Tab：设置、日志、报表、Pro。

  1. 工作间隔 — 免费 30 / 45 / 60 分钟。60 觉得太久，先改 45。
  2. 休息前通知 — 关，或提前 2 分钟。Pro 还有 1 / 3 / 5 分钟。
  3. 遮罩外观 — 1.2.1 起可换背景图和透明度。倒计时要能看清。
  4. 工作备忘 — 可选。遮罩上写一句，日志只留在这台 Mac。设置里的日志 Tab 可以查看或分享。
  5. 晚睡提醒和菜单栏随手记在 1.3.0（审核中）。点「先不睡」不会打断当前这段工作。这两项都不锁 Pro。
  6. Pro 只多这些：任意间隔、休息时长 1–60 分钟、更多跳过/预警、键鼠闲置检测、7 天 / 30 天 / 本年报表。恢复购买：设置 → Pro，用付款时的同一 Apple ID。

6. 怎么退出

打开菜单栏面板，点退出。关掉设置窗口不会退出 App，它是菜单栏常驻。现网 1.2.1 仍显示 Quit Up2Stretch，1.3.0 显示 Quit Up2Reset。
