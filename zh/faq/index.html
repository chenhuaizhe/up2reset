常见问题

短答。没写到的请到支持页发邮件。

Up2Reset 是什么？

给长时间写代码、设计、写作、学习的人用的原生 macOS 菜单栏应用。到点盖住所有屏幕，提醒你站起来。

打开了，窗口去哪了？

没有 Dock 窗口。看屏幕右上角菜单栏的计时器。菜单栏太挤时，系统可能把它收进折叠箭头里，拖出来即可。逐步说明见怎么用。

会收集我的数据吗？

不会。设置、备忘、今日统计和报表都在这台 Mac。没有账号，没有分析 SDK。隐私政策。

需要辅助功能权限吗？

不需要，也不要开。闲置检测读的是系统闲置时长，不是全局键盘鼠标监听。

和 Stretchly、Time Out、Apple Watch 站立圆环有什么不同？

Stretchly 是 Electron。Time Out 是同类工具。Up2Reset 是原生 Swift，全屏遮罩盖住所有显示器，数据只留本机。Watch 站立圆环统计站立小时，不会在你改 diff 改到第九十分钟时盖住 IDE。Stretchly 被 Gatekeeper 拦住见Stretchly 在 Mac 上无法打开。Time Out 3.1 要 macOS 26 见Time Out 需要 macOS 26。

为什么 App Store 上写的是 Up2Stretch？

现网 listing 仍是 Up2Stretch 1.2.1。和 Up2Reset 是同一个 App，Bundle ID com.tool.Up2Stretch，Apple ID 6447865036。1.3.0 已提交审核，过审后商店显示名改为 Up2Reset；购买和 Bundle ID 不变。

需要哪个 macOS 版本？

macOS 14.6 或更高。旧文案里写 13.2 的已经过时。

Pro 有什么？

任意工作间隔、休息时长 1–60 分钟、更多跳过/预警、键鼠闲置检测，以及 7 天 / 30 天 / 本年本地报表。年订或买断，都走 Apple。用付款时的同一 Apple ID，在设置 → Pro 恢复购买。

刚坐下，遮罩就弹出来了。

阅读、看视频也算坐着——硬计时器就是这个意思。如果人真的离开了，走前先暂停，或打开 Pro 闲置检测。合盖和锁屏在免费版就会停表。

可以跳过休息吗？

可以。跳过是推迟遮罩，不是把今天剩下的提醒都取消。默认延迟 10 分钟。Pro 可以改这个时间。

可以换遮罩背景吗？

可以，1.2.1 起就能在设置里选图片和透明度，让倒计时仍然可读。

1.3.0 有什么？

已提交审核，现在商店里还没有。过审后 listing 改名 Up2Reset，并加上晚睡提醒（点「先不睡」不会打断当前工作）、菜单栏随手记、跳过 / 已走动可选长按 3 秒，以及英、简中、繁中、日、韩、德、法、西。这些都不锁 Pro。

报表会跟我到另一台 Mac 吗？

不会。全部本地，故意没有 iCloud 同步。

怎么退出？

打开菜单栏面板，点退出。现网 1.2.1 仍显示 Quit Up2Stretch，1.3.0 显示 Quit Up2Reset。关掉设置窗口不会退出 App，它是菜单栏常驻。
