Up2Reset / Stretchly on Mac

Stretchly 在 Mac 上无法打开

这是 Gatekeeper，不是安装包坏了。Stretchly 未签名。Homebrew 官方 cask 已停用。你可以按作者的方法强行打开，也可以装 Mac App Store 里已签名的原生遮罩。

你看到的是什么

第一次打开时常是这几句：

  • 「Stretchly」无法打开，因为无法验证开发者。
  • macOS 无法验证此 App 是否包含恶意软件。
  • Apple 芯片上还要清 quarantine 才能启动。

这是 Gatekeeper。作者自己写了：应用没有签名（苹果开发者签名要钱，他们不发签过名的 Mac 包）。说明在 Stretchly downloads。

为什么会这样

  1. 未签名。 经过公证的 Mac 应用不会弹这窗。
  2. Electron。 跨平台托盘应用，在 Mac 上要背一整套 Chromium，还要自己处理 Gatekeeper。
  3. 官方 brew cask 已停用。 默认 tap 的 brew install --cask stretchly 过不了 Homebrew 的 Gatekeeper 检查。公式页标了 disabled（formulae.brew.sh/cask/stretchly）。作者自己的 tap 还在，大家复制的那一行不行了。

这不表示 Stretchly 是恶意软件。表示「一行 brew 装上」这条路已经断了。

还想继续用 Stretchly

  1. 从 GitHub Releases 或官网下载页装。
  2. Intel：系统设置 → 隐私与安全性 → 仍要打开。或在 Finder 里按住 Control 点图标 → 打开。
  3. Apple 芯片：下载页写了用 xattr -r -d com.apple.quarantine 清隔离属性。这是绕过隔离，不是签名。
  4. Homebrew：用作者写明的完整 tap 名。不要指望默认 cask。

跑起来之后，推迟结束仍可用 ⌘X 跳过。Reddit 上第二常见的抱怨是这个。

如果任务是「挡住屏幕直到我站起来」

Stretchly 要做的事没变，坏的是 Mac 安装路径。Up2Reset 是原生 Swift 菜单栏计时器：

  • Mac App Store 签名，不用「仍要打开」，不用 xattr。
  • 所有显示器全屏遮罩，热插拔会重建。
  • 不要辅助功能权限。闲置检测（Pro）读系统闲置时钟，不是全局监听。
  • 无账号、无分析 SDK。设置只在这台 Mac。
  • 系统要求 macOS 14.6+，不需要 Tahoe。

商店现用名仍是 Up2Stretch（1.2.1）。1.3.0 审核中，会把 listing 改成 Up2Reset。Bundle ID 仍是 com.tool.Up2Stretch，Apple ID 6447865036。
