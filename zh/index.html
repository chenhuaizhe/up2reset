系统久坐提醒很容易划掉。盖住屏幕就不容易。

macOS 可以弹一下。你会把它滑掉，继续敲。Up2Reset 是给「忘了自己还有身体」的那一小时用的：所有显示器变暗，短休息倒计时，完事就让开。

  1. 00:00
    开始一段工作。计时器在菜单栏，不占 Dock。
  2. 58:00
    想要的话，休息前几分钟会有系统通知。
  3. 60:00
    所有屏幕被盖住。站起来。动一动。如果开了工作日志，写一句刚才在做什么。
  4. 05:00
    确认已走动。遮罩关掉。下一段开始。

它具体做什么

  • 菜单栏计时 暂停、继续、重新计时，看今日工时和休息次数，不用离开当前 App。
  • 全屏遮罩，所有显示器 休息中途插拔屏幕，遮罩会按同一场休息重建，而不是消失。
  • 跳过，过一会儿再叫 开会就跳过。它会按设定的延迟再来，而不是下午都不管了。
  • 合盖或锁屏会停表 人不在座位上，不该把这段算成工作，回来也不该立刻被全屏打断。
  • 遮罩上可以写一句工作备忘 下一轮坐下时，至少还记得刚才做到哪。
  • 开机自启 一个要你每天记得打开的久坐提醒，等于没有提醒。
