Up2Reset / Time Out on Mac

Time Out 需要 macOS 26

当前 Time Out 只支持 Tahoe。你在 Sequoia 或 Sonoma 上，商店不会给你装 3.x。这是系统下限，不是你的 Mac 坏了。

你看到的是什么

  • Time Out requires macOS 26.0 or later
  • Time Out now requires a minimum of macOS Tahoe (26.0)
  • Mac App Store：此 Mac 不满足系统要求
  • 更新后在 Sequoia 上打不开

Dejal 官网写最新是 3.1，需要 macOS 26.0 或更高版本。Mac App Store 页面的更新说明一样。官网仍提供 2.9.7 给 macOS 10.15 或更高：dejal.com/timeout。

为什么会这样

Time Out 3 按 Tahoe 重做（Liquid Glass、新主题编辑器）。Mac App Store 允许提高最低系统。Sequoia 上的产品页会直接拒绝安装。这不是 Gatekeeper，也不是 Apple ID 问题。

以前在商店买过，本机如果还留着 2.x 安装包，还可以继续用。商店不会在旧系统上发给你 3.x。Dejal 给的退路就是直装 2.9.7。

还想继续用 Time Out

  1. 留在 Sequoia：从 Dejal 下 2.9.7，不要升到 3.1。
  2. 已经在 Tahoe：用官网或商店的 3.1。
  3. 直装 / 商店 / Setapp 权限和功能不完全一样，Dejal 另有说明。把 Sequoia 用户扔下的是系统下限这件事。

Time Out 做了二十多年。这页不是悼词。给的是这周还要遮罩、却搜到系统要求的人。

需要在 macOS 14.6–15 上跑已签名遮罩

Up2Reset 是原生 Swift 菜单栏久坐提醒。系统要求 macOS 14.6+，不是 26。

  • 所有屏幕全屏遮罩。要的是站起来，不是 20 秒护眼。
  • Mac App Store 签名，没有「无法验证开发者」。
  • 休眠和锁屏会暂停计时。Pro 加键鼠闲置，避免吃完午饭一回来就被盖屏。
  • 跳过只是推迟，不是取消今天剩下的提醒。
  • 无账号、无分析 SDK。报表只在这台 Mac。

商店显示名是 Up2Reset（1.3.0）。同一应用，Bundle ID com.tool.Up2Stretch，Apple ID 6447865036。

在 Mac App Store 获取 怎么用

遮罩免费。自定义间隔和闲置检测是 Pro。

其实是 Stretchly 打不开？

未签名 Electron + 停用的 Homebrew cask 是另一件事：Stretchly 在 Mac 上无法打开。
